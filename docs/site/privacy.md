# 隐私政策

最后更新:2026-09-08

**一句话:我们不收集你的任何数据。**

- **所有计算在你的设备上完成。** 你输入的收入、支出、资产等信息只保存在本机(Apple SwiftData 本地存储),永远不会离开你的设备。
- **应用不联网。** WealthClock 没有服务器、没有账号系统、不接入任何分析或广告 SDK、不发送任何网络请求。
- **应用内购买由 Apple 处理。** 一次性买断通过 App Store(StoreKit)完成,我们不接触、也无法接触你的支付信息。
- **出生日期(可选)** 仅用于结果卡上的装饰性"密押"与配色,不参与任何计算,同样只保存在本机。
- **你的数据你做主。** 可随时在"设置"中导出全部记录(JSON/CSV),或一键删除全部数据;卸载应用即彻底移除所有数据。

如对本政策有任何疑问,见[支持页](/WealthClock/site/support/)。
